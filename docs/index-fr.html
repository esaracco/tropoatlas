TropoAtlas
Applications libres pour vos collections · GPLv3

Organisez, explorez et illuminez vos collections

TropoAtlas crée le pont entre votre catalogue numérique et vos rayonnages réels. Gérez votre musique, vos films et vos livres via des applications dédiées, et localisez instantanément vos œuvres sur vos étagères grâce à des bandeaux LED connectés.

Matériel IoT

Repérage physique sur vos étagères par LEDs connectées

L'innovation maîtresse de TropoAtlas réside dans le lien direct et tangible entre vos données logicielles et votre espace de vie réel.

Retrouvez vos œuvres en un clin d'œil

Des bandeaux LED adressables fixés le long de vos étagères illuminent l'emplacement exact correspondant aux albums sélectionnés ou aux filtres actifs. Fini les recherches fastidieuses sur les tranches.

  • 1 Firmware ESP32-S3 Mini : Firmware C++ ultra-léger (firmware/led-controller) pilotant les bandeaux LED WS2812B via des requêtes HTTP locales.
  • 2 Pilote matériel centralisé : Package partagé autonome (@tropo/leds) orchestrant les couleurs, luminosités et effets de clignotement.
  • 3 État actuel : Actif et pleinement opérationnel dans TropoAudio pour les vinyles et CD, et conçu pour s'étendre aux supports physiques de films (TropoCine) et livres (TropoBiblio).

💡 Conçu pour les Makers : L'ensemble du code source du firmware et les schémas de câblage sont libres et inclus dans le dépôt, prêts à être téléversés sur un microcontrôleur ESP32 accessible.

Architecture & Valeurs

Conçu sur des principes logiciels rigoureux

TropoAtlas est structuré sous la forme d'un monorepo découplé et propre, garantissant respect de la vie privée, extensibilité et confort de développement.

🔒

Vie privée & Local-First

Aucun pistage, aucune télémétrie, aucun compte requis. Vos collections restent strictement sur votre machine ou votre serveur privé.

📦

Monorepo NPM modulaire

Gestion d'état partagée (@tropo/core), composants et tokens d'interface (@tropo/react), et pilotes matériels (@tropo/leds).

🔌

Architecture de plugins

Les fournisseurs de données (Discogs, TMDB) sont isolés dans des plugins de domaine, préservant l'indépendance totale des interfaces.

ARCHITECTURE DU MONOREPO NPM WORKSPACES 
tropoatlas/
├── apps/
│   ├── tropoaudio/          # Gestionnaire de musique (Discogs, repérage étagères LED)
│   └── tropocine/           # Gestionnaire de films (TMDB, casting & réalisateurs)
├── packages/
│   ├── core/                # Abstraction stockage, store Zustand, export/sauvegarde
│   ├── react/               # Modales partagées, design tokens, composants UI
│   └── leds/                # Client HTTP autonome pour bandeaux LED adressables ESP32
├── plugins/
│   ├── audio/discogs/       # Fournisseur de données API Discogs (@tropo/discogs)
│   └── cine/tmdb/           # Fournisseur de données API TMDB (@tropo/tmdb)
└── firmware/
    └── led-controller/      # Firmware C++ ESP32-S3 Mini pour bandeaux LED WS2812B
Démarrage Rapide

Lancement local ou déploiement en production

Toutes les applications de TropoAtlas se compilent en bundles statiques ultra-performants et légers.

Lancement via Docker Compose

Démarrez simultanément TropoAudio (port 3000) et TropoCine (port 3001) avec une seule commande :

TERMINAL BASH
# Lancer toutes les applications
docker compose up

# Ou lancer une seule application
docker compose up tropoaudio
docker compose up tropocine

Développement local dans le monorepo

Clonez le dépôt, installez les dépendances du monorepo et lancez les serveurs de développement Vite :

TERMINAL BASH
git clone https://github.com/esaracco/tropoatlas.git
cd tropoatlas
npm install

# Lancer les serveurs de développement
npm run dev:audio
npm run dev:cine
