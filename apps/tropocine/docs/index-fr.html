Organisez, explorez et redécouvrez votre collection de films

TropoCine est un gestionnaire de collection cinématographique sous licence libre. Synchronisez vos films depuis TMDB, explorez réalisateurs et acteurs, et parcourez votre vidéothèque en toute simplicité.

Fonctionnalités

Conçu pour les passionnés de cinéma

Un gestionnaire réactif et modulaire adapté aux cinéphiles et aux grandes vidéothèques.

Recherche & Filtres Instantanés

Filtrez et triez votre collection en temps réel par réalisateur, acteur, genre, année de sortie, note ou date d'ajout.

Sécurité & Proxy d'API

Architecture avec proxy sécurisé (Apache/Nginx). Vos jetons d'API et identifiants ne sont jamais exposés côté navigateur.

Architecture Découplée

Monorepo NPM clair séparant composants d'interface, gestion d'état, cache, et plugins de données.

Sauvegardes Portables

Exportez et restaurez des archives complètes de votre collection avec métadonnées et affiches dans des fichiers ZIP portables.

Déploiement

Démarrage rapide

Lancez TropoCine en local ou avec Docker, et déployez-le derrière un reverse proxy Apache/Nginx.

Configuration en développement local Bash
# 1. Cloner le dépôt et installer les dépendances
git clone https://github.com/esaracco/tropoatlas.git
cd tropoatlas
npm install

# 2. Configurer les variables d'environnement
cp apps/tropocine/.env.sample apps/tropocine/.env

# 3. Lancer le serveur de développement
npm run dev:cine
