Le pont entre votre collection numérique et physique

TropoMusic est un gestionnaire de collection musicale sous licence libre. Synchronisez vos albums depuis Discogs, enrichissez-les de métadonnées personnalisées et localisez vos disques sur vos étagères grâce à des rubans LED connectés.

Fonctionnalités

Conçu pour les passionnés de musique

Un gestionnaire réactif et modulaire adapté aux grandes collections de vinyles et de CDs.

Recherche & Tri instantanés

Filtrez et triez votre collection en temps réel par artiste, année, date d'ajout, note ou emplacement physique sur votre étagère.

Métadonnées personnalisées

Enrichissez chaque album de champs personnalisés : emplacement exact, prix d'achat et styles simplifiés.

Localisation LED physique

Sélectionnez un album, des styles ou des artistes à l'écran, et les emplacements s'illuminent sur votre étagère grâce à des rubans LED.

Sécurité & Proxy API

Architecture avec proxy sécurisé (Apache/Nginx). Vos jetons d'API et identifiants ne sont jamais exposés côté navigateur.

Architecture modulaire

Monorepo NPM clair séparant composants d'interface, gestion d'état, pilotes matériels et plugins de données.

Sauvegardes portables

Exportez et restaurez des sauvegardes complètes avec métadonnées et pochettes sous forme d'archives ZIP portables.

Matériel IoT

Trouvez vos disques en un clin d'œil

Déploiement

Démarrage rapide

Lancez TropoMusic en local ou déployez-le avec Docker.

Configuration en développement local Bash
# 1. Cloner le dépôt et installer les dépendances
git clone https://github.com/esaracco/tropoatlas.git
cd tropoatlas
npm install

# 2. Configurer les variables d'environnement
cp apps/tropomusic/.env.sample apps/tropomusic/.env

# 3. Lancer le serveur de développement
npm run dev
