# @tropo/react

A collection of generic, reusable React components, design tokens, and UI hooks used across the TropoAtlas ecosystem.

## Shared Features

- **Theme System**: Zero-FOUC theme switching, CSS custom properties, and multi-theme palette support (`themes.css`, `ThemeSelector`).
- **Modals & Dialogs**: Reusable dialog components (`ButtonModal`, `ConfirmModal`, `InfoModal`, `AboutButton`).
- **Controls & Filtering**: Generic search inputs (`Search`), sort selectors (`SortControl`), and custom inputs (`Checkbox`).
- **Navigation & Utilities**: Back-to-top button (`ScrollButton`), language selection (`LanguageSelector`), PWA update notification (`PwaReloadPrompt`), and common React hooks.
